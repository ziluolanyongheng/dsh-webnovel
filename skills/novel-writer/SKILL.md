# novel-writer：长篇怎么写下去

长篇写坏，多半不是某一章写得差，而是写到第三十章忘了第三章立的规矩、用烂了同一招、把用户说过的话忘了。这个技能管的就是这些：**规矩放在文件里，每章用文件和脚本把自己卡住。**

## 一、书的文件结构

每本书一个文件夹，第一次用时按这个样子建：

```
<书名>/
  提示词/专属提示词.md      # 这本书的全部规矩，模板见 templates/book-bible.md
  剧情/章节/第001章.md      # 一章一个文件，文件名带数字
  资料/                     # 原著、设定、参考（可选）
通用写作提示词.md           # 跨书通用，放在书稿根目录（可选）
```

专属提示词的模板在本技能的 `templates/book-bible.md`，复制过去再填。账本（想法、招牌戏、伏笔、钱、谁知道他的底）都在里面，一本书不要拆成很多文件。

**规矩分三层，下层盖上层**：本技能族的默认规矩 → 通用写作提示词 → 专属提示词。专属提示词里，新结论写在最前面一节，并注明“跟下面冲突的以这节为准”；旧节留着当素材，不要去改写历史。

## 二、续写只读这些

不要读全部上下文，长篇读不完，读多了反而跟着旧章的毛病走：

1. 专属提示词（通用写作提示词有就也读）。
2. 最近一两章的全文。
3. 这章要用到的细节，用搜索工具 grep 章节文件夹，不要整章重读。

用户明确说“先通读一遍”才通读。

## 三、写之前想七件事（写在草稿头上，写完删）

1. **这章变了什么**：关系、局势、得失、秘密、计划，至少一样。想不出来，这章不该单独存在。
2. **爆点是哪一下**：全章最亮的那一段是什么，读者看到哪句话会爽。
3. **这章承接哪里**：紧接、转场还是插叙；上一章怎么开头、怎么收尾，这章都要换。
4. **现实会怎样**：主角拿出东西或做了大事，先想真实世界的反应，不信、眼红、误读、传开要时间。
5. **谁知道了什么**：有没有人比上一章多知道了主角的底；超了就改情节。
6. **这章的人想要什么**：要收的女人写她自己的需求和心里话；配角有自己的算盘，不是来递话的。
7. **这个桥段写过吗**：翻账本。写过的招牌戏要么一句带过，要么换新东西。

想的时候先列两三个走法，挑最不像公式的那个；第一个冒出来的走法多半是套路。

## 四、一章的循环

1. 按第二节读，按第三节想。
2. 写正文，一章一个场景，三四千字（书里另定的照书）。怎么写看 `novel-craft`；同人先看 `novel-fanfic`。
3. 跑查重，不过就改到过：看 `novel-check`。
4. 过事实核查：看 `novel-factcheck`。
5. 专项 grep：人物称呼变了没有（比如认主后私下还在说“你”）、这章出场的人上一次的状态。
6. 更新专属提示词里的账本和“写作进度”。
7. 汇报，见第七节。

**设定冲突先对前文**：写到人物、地点、时间线上的旧事，grep 一次再下笔，不靠印象。改完一处矛盾，把同类的也搜一遍。

## 五、连续写多章

用户说“写到第几章”“继续写”：

- 不要每章停下来问“要不要继续”，一路写，每章照样走第四节，查重不过不算写完。
- 日常章、支线章自己定；只在长线岔口才问用户（见 `novel-grill`）。
- 每写完几章看一眼这几章的开头和章尾是不是一个样。
- 写到额度或时间快用完时，先把进度记进专属提示词，写清下一章从哪接。

## 六、用户的话怎么记

这条比什么写法都要紧。

- **照原话记，不加码。** 用户说“要体现”，不等于“每章都要”；用户没说的细则不要当成他的要求。记的时候尽量抄原话。
- **当场落文件，不等以后。** 对话会被压缩，文件不会。
- **先判断放哪层**：对所有书都成立的进通用写作提示词，只对这本书成立的进专属提示词；不确定就放专属。
- **用户改口以最新一次为准**，旧的划掉或标作废，别两条并存。
- **改提示词和章节前先留备份**（`文件名.bak-日期-事由`），大改之前尤其要留。
- 用户批评一章时，别只改那一章：把批评抽成一句规矩写进文件，再搜一遍同样的毛病还出现在哪些章。
- 用户夸一段，把手法（不是原文）记进“用户认可的写法”。
- 用户说“不要了”的东西，从大纲里删掉，不要换个名字又写回来。

## 七、怎么汇报

写完一批给一段短报告：写到第几章、这批变了什么、查重和核查的结果（跑了什么、过没过）、有没有没解决的矛盾、下一章从哪接。查重没过或者跳过了某一步，直说。不复述剧情，不列长表，不问“还需要我做什么”。

## 八、开新书和新卷

- 开书：先 `novel-grill` 拷问，同人再加 `novel-fanfic` 读原著，然后填专属提示词，列第一卷的事件池和意外池，再动笔。
- 开卷：先做上一卷的卷末自查（见 `novel-craft` 的 `references/plot.md` 末尾），再拷问，再列池子。
- 不写完一卷就回头大改；但用户点名的毛病立刻改。

## 九、不写什么

这几条不随用户、不随书改变：

- 不写涉及未成年人的性内容或亲密内容，包括外形幼态的角色，不管设定里她几百岁。
- 不写以强奸、奸尸、性虐杀当卖点的情色内容。
- 不写真实人物的性内容，正文不出现真人姓名配亲密戏。
- 不逐字搬运受版权保护的原著和现代作品。
