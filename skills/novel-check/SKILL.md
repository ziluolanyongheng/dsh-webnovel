# novel-check：查重

脚本在本技能目录的 `scripts/` 下，只用 Node，没有依赖。下面的 `<技能目录>` 换成加载本技能时给出的目录，路径带空格要加引号。

## 写完每一章

```sh
node <技能目录>/scripts/check-chapter.mjs <章节路径>
```

常用参数：

| 参数 | 含义 | 默认 |
|---|---|---|
| `--prev` | 跟前面几章比 | 5 |
| `--n` | 几个字算重复；严查用 6 | 8 |
| `--min` `--max` | 字数范围 | 2800、5500 |
| `--banned` | 本书的套话黑名单，一行一个 | 无 |
| `--source` | 原著文件或文件夹，查逐字重合（同人必加） | 无 |
| `--source-n` | 几个字算跟原著重合 | 12 |
| `--json` | 输出 JSON | 否 |

退出码 1 表示有问题。判失败的有：对话超两成半、跟前几章重复或本章内部重复超过 5 处、命中套话、跟原著重合。“极短台词”只是提示，逐句看，是哑谜命令就把话说全，是自然的应答就留着。

章节文件放在同一个文件夹，文件名带数字（`第12章.md`、`12.md` 都行），脚本按自然序找前几章。

## 写完一卷，或用户说太重复

```sh
node <技能目录>/scripts/check-volume.mjs <章节文件夹> --from 41 --to 80
```

输出每章的字数、对话占比、开头、章尾的表，加上出现在三章以上的句子、跨章一字不差的台词、连续两章开头撞车。

地名人名也会被报出来，所以不是每条都要改。判失败的只有：8 字以上或出现 5 章以上的句子、三章以上的同一句台词、开头撞车、对话超标。

## 起名之前

```sh
node <技能目录>/scripts/check-names.mjs <书稿根目录> 名字一 名字二
```

查全部书稿里用过没有、是不是烂大街、有没有生僻字。

## 脚本查不出来的，自己查

重复不只是句子一样，脚本只抓字面。这些要自己看：

- **骨架重复**：连续几章都是“挑衅 → 打脸 → 崇拜”。看 `check-volume` 那张表的开头章尾，再翻账本。
- **招牌戏重复**：动作一样、换了词。对照专属提示词的“招牌戏账本”。
- **同一个意思翻来覆去说**：换了说法还是在说同一件事，删掉。
- **称呼**：关系变了的人，grep 她的台词看称呼和口气跟上没有。
- **万能动作**：抬眼、低头、笑了一下、顿了顿，一章里数一下。发现本书的新口头禅，加进 `--banned` 的黑名单文件。

## 怎么改

- 从最长的重复改起，长的是整段搬过来的。
- 不是换同义词，是换写法：换一个动作、换一个感官、换一个角度，或者这句不要了。
- 改完再跑一遍，没过不算完。
- 汇报时写实际结果，比如“跟前 5 章重复 2 处，已改到 0”，不写“已查重”。
