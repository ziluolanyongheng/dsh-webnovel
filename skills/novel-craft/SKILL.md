# novel-craft：正文写法

默认是一本要爽、要快、主角很强的长篇。书里另定基调的，照专属提示词。

## 每章都守的十条

1. **每章一个爆点**：出手、打脸、反转、亮牌，或美人的极致反差，写成全章最亮的一段。三五章一场高潮，卷末最大一场。
2. **主角的底藏住**：实力、来历、金手指、幕后手笔，只有他和读者知道。对手猜不到是他。
3. **每章都有东西变**：关系、局势、得失、秘密、计划。
4. **一章一个场景**：一个地方、一段连续时间，不来回切；大事拆成几章。默认三四千字。
5. **描写压过对话**：引号里的话占两成到两成半，每章至少一两段不带对话的大描写。
6. **话要说全**：人说话是完整的句子，把要什么、为什么说出来；不写“过来。”“坐。”这种哑谜。
7. **直白**：比方后面跟一句大白话，章尾悬念看得懂，要藏就整件不提，要提就说清楚。
8. **反应要真**：大事传开要时间，有人不信、眼红、误读、反扑；懂行的人的震动一层层往外传。
9. **不重复**：招牌戏全书只完整写一次；同一句话不进三章；开头和章尾跟上一章不一样。
10. **不煽情**：不动不动就哭，不写格言金句，不把人情账挂在嘴上。

## 该读哪份细则

| 现在的情况 | 读 |
|---|---|
| 写打斗、宫宴、发布会、商战，或用户说不够爽 | `references/shuang.md` |
| 用户说太重复、谜语人、对话多、文笔差 | `references/style.md` |
| 新人物出场、关系推进、起名 | `references/character.md` |
| 开卷列池子、卷末自查、用户说太公式 | `references/plot.md` |
| 写钱、技术、专业内容、出国、物价 | `references/world.md` |

细则是长清单，用到才读，不要一次全读。

## 改章节

用户点名的毛病，先把批评抽成一句规矩写进专属提示词，再改这一章，再搜同样的毛病在别的章有没有。改完重新跑 `novel-check`。不要只换几个词敷衍过去，段落结构有问题就重写这一段。
