# novel-fanfic：先学原著

百科梗概不算读过原著。开书和每卷开写前，先读几章原文。

## 读什么

- 本书 `资料/` 里有就读，没有就上网找免费章节。
- 读开头、一场打斗、一场人物对话、用户最关心的人物出场那几章。
- 找不到原文就直说，别凭印象写一份“原著写法”。

## 在专属提示词里记一节“原著写法”

- 叙述人称和口吻。
- 句子长短和节奏。
- 常用词和术语：境界、招式、地名、称呼。
- 各人说话的口气和口头禅。
- 打斗怎么升级，笑点怎么写。
- 两三段短样文，每段几句，当校音用。

## 下笔

- 笔调往原著靠，原著人物说话要像原著里的他们。
- 主角的爽点、藏底牌、对话占比、话说全这些仍照 `novel-craft`。
- 时间线和人物关系先对原著，改动要有说法。
- 用户说“这个不要”的原著人物或剧情，就是不要。
- 原著人物第一次出场，用读者认得出的外貌特征写。

**日本轻小说、异世界原著**：叙述人称、短段落、视角切换、敬称、用词、单位（米、分钟）、章名都照日式写，不用一盏茶、三寸、几里这种中式老说法，不加原著没有的系统。

## 只学写法，不搬原文

原著是读来学的，不是抄的。剧情和招式可以借，句子自己写。每章加 `--source` 跑一遍：

```sh
node <novel-check 技能目录>/scripts/check-chapter.mjs <章节> --source <原著文件夹>
```

重合的段落全部改写。原著文件不要放进要发布的仓库。
