# novel-romance：把张力写出来

好看的暧昧戏靠**慢、近、具体、反差、话说透**，不靠露骨。

## 边界

这几条是写这类戏的前提，不随书改变：

- **全员成年，且看起来就是成年人。** 未成年阶段不写亲密内容。角色外形幼态、设定是学生或小孩的，不写，不管设定里她多少岁。
- **双方自愿。** 涉及权力落差、调教类的戏，要写清楚她自己想要、有安全词、说了就停。
- **尺度**：舌吻、揽腰、隔衣触碰、腿和脚的特写为止，衣着到内衣泳装为止。到上床这一步就转场。不写器官、性行为细节和性方面的体液。
- **不知情的人不卷进来**：男友、家人、路人不被牵扯进性内容。
- **真人不写。**

## 开写前定四件事（写在草稿头上，写完删）

1. **由头**：这场从剧情里哪件事长出来。上一场用过的这场不用。
2. **核心**：一场只挑一个核心动作或物件，从她的身份长出来，全书只归她一个人。
3. **谁主动**：她撩他、他接住、她先撩被他翻过来、两个人较劲。轮换。
4. **这场之后变了什么**：一个称呼、一条规矩、心里认了一件事。没变化的戏不写。

## 一场戏的骨架（顺序可换，不必每拍都有）

- **场子**：一两句地方和光，要跟戏有关。
- **靠近**：距离一级级缩短，每缩一级给一个具体的东西（声音、温度、气味）。
- **特写**：挑一两处（手、颈、背、腿、脚），写颜色和光、温度、她怎么摆、他碰了她怎么回应。一场最多两处。
- **台词交锋**：撩人的话要说透，不说半句让读者猜。
- **她的心里话**：两三句，想要和害羞怎么搅在一起，人前她是谁、此刻在干什么。
- **升级**：话 → 手 → 吻。到线就转场：跳到第二天、门外有人叫、或用一句事后的话收。
- **收尾**：每回换。

## 写法要点

- **慢**：一个动作拆成三拍（握住脚踝 → 拇指压在踝骨内侧 → 往上推半寸停住）。过场一句带过。
- **近**：指纹、脉跳、睫毛、呼出来的那口热气。
- **一场挑一种声音当节拍**：鞋跟、铃、呼吸、水开。
- **反差**：人前身份越高，这场越低。反差写一次就够狠，别一场反复点。
- **女人自己主动**：欲望是她自己的，不写“被迫”。路数从她自己身上来。
- **男主口气不固定**：看人看场合换，有时短句，有时把话说透，有时逗她损她哄她，一个人身上也别一种腔调用到底。事后把人接住。
- **舌吻**：舌尖怎么探、缠，嘴里的味道，呼吸乱，分开时的样子；每回写法看她是谁、在哪、什么心情。
